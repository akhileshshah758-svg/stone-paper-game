# Stone Paper Scissors Game

A simple, interactive, and entertaining Stone Paper Scissors game developed using HTML, CSS, and JavaScript. Play against the computer, choose your move, and test your luck and strategy in this classic game.

## Features

- **Interactive Gameplay:** Choose between Stone, Paper, and Scissors.
- **Computer Opponent:** Play against randomly generated computer choices.
- **Winner Detection:** Automatically determines the winner based on the game rules.
- **Instant Results:** Get immediate feedback after every move.
- **Simple User Interface:** Enjoy a clean and user-friendly gaming experience.

## Technologies Used

- **HTML5:** Provides the structure of the game.
- **CSS3:** Adds styling and improves the visual appearance.
- **JavaScript:** Handles game logic, user interactions, and winner determination.

## How to Play

1. Open the game in your web browser.
2. Select Stone, Paper, or Scissors.
3. The computer randomly selects its move.
4. The game compares both choices and displays the result.
5. Play multiple rounds and try to achieve the highest score.

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd stone-paper-scissors-game
```

**3. Run the game**

Open the `index.html` file in your preferred web browser.

No additional installation or dependencies are required.
